documentation publiée.

Une page historique reste la référence publique tant que ses consommateurs
n'ont pas basculé vers `Silex-Documentation`. Dès qu'une page française entre
en réécriture ici, sa source historique est gelée ; les écarts apparus après le
commit ci-dessus devront être réconciliés avant le basculement.

## États

- **à faire** : la page n'a pas encore été restructurée ;
- **partiel** : la partie appartenant au langage est prête, mais une autre
  section publique reste à extraire ;
- **à relire** : la nouvelle page française est prête pour une relecture
  humaine ;
- **interne** : la page reste dans le dépôt du compilateur ;
- **basculement** : le contenu sera remplacé par un lien ou un index lors du
  changement de source publique.
